## 🆘 IF SOMETHING DOESN'T WORK

### "npm: command not found"
- Node.js not installed
- Download from: https://nodejs.org/
- Restart computer after install
- Try again: `node -v`

### "Port 3000 already in use"
- Another app using same port
- Run: `PORT=3001 npm run dev`
- Visit: http://localhost:3001

### "Build fails"
- Delete node_modules folder
- Run: `npm install`
- Try BUILD script again
- See: `BUILD_INSTRUCTIONS.md` → "Troubleshooting"

### "Database error"
- Delete `dev.db` file (if exists)
- Run: `npx prisma db push`
- Run: `npx ts-node prisma/seed.ts`

**More help:** See `BUILD_INSTRUCTIONS.md`
